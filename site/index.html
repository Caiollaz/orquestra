— os naipes

Tudo que uma orquestra precisa pra tocar junto.

latão

Canvas multi-agente

Terminais PTY reais num canvas com pan e zoom. Cada nó é um processo vivo: arraste, redimensione, encerre.

percussão

Comunicação automática

Ligue nós com arestas: um agente escreve ⇢nome: msg e o orquestra entrega no chat do outro. Eles se coordenam sozinhos.

cordas em breve

Papéis

Presets em markdown com variáveis. Um clique semeia o prompt do agente: PO, revisor, implementador — o elenco que você quiser.

madeiras em breve

Floors

Cada agente num git worktree isolado. Trabalho paralelo em branches separadas, sem um pisar no código do outro.

— a partitura

Três movimentos e a orquestra toca.

1. Abra a pasta do projeto

Aponte o orquestra pro repositório onde o trabalho vai acontecer.

2. Some os músicos

+ claude + shell + contexto — cada botão põe um nó novo no palco.

3. Conecte e reja

Arestas levam mensagens de um nó pro outro. Você acompanha tudo e intervém em qualquer terminal, a qualquer momento.
